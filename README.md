## 🚀 Featured Projects

### 🤖 [RagLab — Enterprise ERP AI Assistant](https://github.com/OzgurUUU/AIForERP)
> *The most complex project I've built. A production-ready, fully local AI system.*

A full-stack RAG (Retrieval-Augmented Generation) platform that lets you query your ERP database in plain language. **No cloud. No API keys. Zero recurring AI cost.**

```
User: "Show me unpaid invoices for Beta Logistics this month"
AI:   Streams a precise answer from your own database in ~3 seconds ⚡
```

**Tech:** `ASP.NET Core 9` `Angular 18` `Llama 3 8B` `Qdrant` `ML.NET ONNX` `Semantic Kernel` `MySQL` `Docker Compose`

**Key Engineering Decisions:**
- 🧠 **Hybrid AI Pipeline** — BERT (ML.NET/ONNX) for lightning-fast local embeddings + Llama 3 for reasoning
- 🌊 **SSE Streaming** — Token-by-token response streaming for a ChatGPT-like UX
- 🔒 **Production Security** — JWT auth, role-based access control, IP-based rate limiting
- 👍 **Feedback Loop** — Users vote on answers; incorrect responses logged to MySQL for future fine-tuning
- 🐳 **One-Command Deploy** — Full system (AI, Vector DB, API, UI) via `docker compose up -d`
